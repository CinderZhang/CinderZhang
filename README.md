### The DRIVER Framework

**Define · Represent · Implement · Validate · Evolve · Reflect**

A structured methodology for AI-augmented finance education — teaching students to work *with* AI as a thinking partner, not a shortcut. DRIVER powers three textbooks under contract with **World Scientific Publishing** (2026):

| Textbook | Repo |
|----------|------|
| Financial Modeling | [`DRIVER-FinancialModeling`](https://github.com/CinderZhang/DRIVER-FinancialModeling) |
| Financial Management | [`DRIVER-FinancialManagement`](https://github.com/CinderZhang/DRIVER-FinancialManagement) |
| International Finance | [`DRIVER-InternationalFinance`](https://github.com/CinderZhang/DRIVER-InternationalFinance) |

→ See the framework in action: [`driver-plugin`](https://github.com/CinderZhang/driver-plugin)
